# SOULPAL — Faith • Growth • You

A responsive single-page SOULPAL prototype for GitHub Pages.

## What's included
- Personalized onboarding
- Study, Talk, Discover Me, Journal and Progress sections
- Theme switcher with saved theme preference
- Three new image-based themes inspired by the latest designs:
  - Bloom — warm peach, blush and lavender
  - Nature — green, turquoise and earthy neutrals
  - Night Sky — deep navy and blue
- Theme changes update the page palette, navigation, buttons, cards and home hero image
- Local browser storage for profile, journal and theme preference

## Files
- `index.html` — main website
- `assets/` — theme imagery

## GitHub Pages
Upload `index.html`, `README.md`, and the complete `assets` folder to the root of the repository, then deploy from `main` / `/(root)` in GitHub Pages.

This is still a front-end prototype. It does not yet have real accounts, a database, central analytics, or a live AI backend.
